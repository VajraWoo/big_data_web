## 输出与复现

在项目根目录实际执行的全量入口：

```powershell
powershell -ExecutionPolicy Bypass -File pipelines/run_silver.ps1 -Mode full
```

新执行自动生成新批次，不覆盖已有成功结果。数据根目录：
`data/silver/silver-full-20260903T154909-6c310067/`。

| 路径 | 内容 |
|---|---|
| reviews/ | 全部保留评论、原文、类型字段、重复组和关联状态 |
| products/ | 按来源行保留的商品元数据 |
| product_keys/ | 每父键一行、键数量与唯一可关联的metadata_id |
| variants/ | 不丢失多对多关系的asin-parent_asin映射 |
| quarantine_reviews/、quarantine_products/ | 独立隔离与原因，即使0行也保留schema |
| profiles/ | 评分、月份、正文长度、商品评论量及其分布 |
| quality.json、run.json | 质量分子/分母、行数去向、schema/血缘、版本、输入摘要、耗时及错误 |
| reviews_schema.json、products_schema.json | Parquet回读schema |
| _staging/、_normalized/ | 可追踪的编号原文分片及分布式规范化中间结果 |

Spark事件日志另在 `data/silver/events/`；完整控制台日志及提交参数在 docs/runs/evidence/。
